Setup (once, ~15 min)

  1. Firebase console → Project settings → Service accounts → Generate new private key. Copy the whole JSON into the GitHub secret FIREBASE_SERVICE_ACCOUNT (repo → Settings → Secrets and variables → Actions).
  2. Telegram: in Telegram talk to @BotFather → /newbot → copy token to secret TELEGRAM_BOT_TOKEN. Send any message to your bot, then open https://api.telegram.org/bot<TOKEN>/getUpdates to find your chat id.
  3. WhatsApp (free, unofficial CallMeBot): add +34 644 51 95 23 to contacts, send it “I allow callmebot to send me messages”, you get an API key → secret CALLMEBOT_APIKEY.
  4. Email: secrets SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS (Gmail: smtp.gmail.com, 465, your address, an App Password), optional EMAIL_FROM.
  5. Optional AI brief: secret ANTHROPIC_API_KEY.
  6. GitHub → Actions → “Daily shop alerts” → Run workflow to test. It then runs daily at 20:00 (Algeria).
